PYTHON COM MATEUS
=================

1. Abra o arquivo index.html em um navegador moderno.
2. O progresso fica salvo no navegador usado.
3. O Playground precisa de internet na primeira execução para carregar o Python.
4. Na área Recursos, o player do YouTube é carregado somente ao clicar.
5. Caso a incorporação seja bloqueada pela prévia, navegador ou extensão, use o botão “Abrir no YouTube”.

Arquivos principais:
- index.html: aplicação completa.
- preview-desktop.png / preview-mobile.png: prévias da interface.
