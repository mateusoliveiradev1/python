PYTHON COM MATEUS — V3
======================

Curso interativo de Python do absoluto zero ao avançado.

COMO ABRIR
1. Extraia o ZIP.
2. Abra index.html no Chrome, Edge ou Firefox.
3. O progresso é salvo no navegador.
4. A primeira execução do Playground precisa de internet para carregar o Pyodide.

O QUE HÁ NESTA VERSÃO
- 26 módulos e 104 aulas completas e únicas.
- Método PRIMM: Prever, Executar, Investigar, Modificar e Criar.
- Parsons Problems para ordenar código.
- Exercícios, erros comuns, glossário e critérios de domínio.
- Checkpoints e evidências obrigatórias para concluir cada aula.
- 18 projetos progressivos.
- Fontes técnicas por aula e página de metodologia.
- Layout responsivo para computador e celular.

ARQUIVOS
- index.html: aplicação completa em um único arquivo.
- preview-desktop.png: prévia da página inicial no computador.
- preview-mobile.png: prévia da página inicial no celular.
