## 📋 Sobre o Projeto

Esta é uma plataforma de aprendizado interativa de Python, pensada para quem está começando do absoluto zero. Cada etapa combina:

- ✅ **Explicação curta** — sem maratona de teoria
- 🎨 **Animação visual** — conceitos sendo executados em tempo real
- ⌨️ **Código executável** — playground Python no navegador (via Pyodide)
- 📝 **Exercícios** — pratique imediatamente o que aprendeu
- 🎯 **Checkpoints** — quizzes para fixar o conteúdo
- 🚀 **Projetos** — 18 projetos progressivos para o portfólio

## 🚀 Como Usar

O projeto é **100% estático** — funciona apenas abrindo o arquivo `index.html` em um navegador moderno.

1. Clone o repositório:
   ```bash
   git clone https://github.com/mateusoliveiradev1/python.git
   ```
2. Abra o `index.html` no navegador
3. Pronto! O progresso é salvo automaticamente no navegador (localStorage)

> ⚡ O playground Python precisa de internet na **primeira execução** para baixar o motor Pyodide. Depois, o navegador pode reaproveitar o cache.

## 🛠️ Tecnologias

- **HTML5 + CSS3** — interface responsiva e escura (tema próprio)
- **JavaScript puro** — sem frameworks, sem dependências
- **Pyodide** — Python 3.12 executando diretamente no navegador via WebAssembly
- **localStorage** — progresso salvo localmente
